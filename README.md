₿ Bitcoin Analytics Dashboard

Financial Performance & Risk Analysis

An interactive Bitcoin financial analytics dashboard built with Python, Streamlit, Pandas, NumPy and Plotly.

This project analyzes historical Bitcoin market data and visualizes price performance, market volatility, investment returns and historical market crashes.

📊 Dashboard Features

KPI Overview: Latest Bitcoin price, total return, annualized volatility and maximum drawdown.

Historical Price Analysis: Interactive Bitcoin closing-price chart.

Candlestick Analysis: Open, High, Low and Close price visualization.

Worst Crash Days: Identification of the 10 worst daily Bitcoin returns.

Yearly Returns: Comparison of Bitcoin's annual performance.

🚀 How to Run the Project

1. Clone the repository

git clone https://github.com/kusum-kumar/bitcoin-analytics-dashboard.git

2. Open the project folder

cd bitcoin-analytics-dashboard

3. Install dependencies

pip install -r requirements.txt

4. Run the dashboard

streamlit run app.py

📈 Project Objective

The objective of this project is to apply financial analytics and data visualization techniques to historical Bitcoin market data, helping users understand market trends, investment performance and financial risk.
